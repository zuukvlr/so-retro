# Instalar no iPhone (Safari)

Pré-requisito: o app já publicado em um endereço HTTPS (veja [HOSPEDAGEM.md](HOSPEDAGEM.md)).

1. Abra o endereço **no Safari** (precisa ser o Safari; Chrome e outros navegadores do iPhone não instalam como app com todos os recursos).
2. Toque no botão **Compartilhar** (quadrado com seta para cima, na barra inferior).
3. Role e toque em **Adicionar à Tela de Início**.
4. Confirme o nome **Só Retro** e toque em **Adicionar**.
5. Abra pelo **ícone na Tela de Início** (não pelo Safari). Ele abre em tela cheia, como um app.
6. Abra uma vez **com internet** para o app guardar tudo para uso offline. Depois funciona sem internet.
7. Vá em **Config.** e preencha os dados da empresa (nome, CPF/CNPJ, telefone, Pix, logo se quiser trocar).

## Compartilhar um PDF

Abra um orçamento ou recibo → **Compartilhar PDF** → escolha WhatsApp, Mail, AirDrop ou **Salvar em Arquivos**.

## Dicas

- Faça um **backup** logo no início e depois com frequência (Config. → Exportar backup → Salvar em Arquivos/iCloud).
- Se o ícone sumir ou o app for apagado, **os dados do app são apagados junto**: sem backup não há como recuperar.
- Para remover o app: segure o ícone → *Remover App*.
